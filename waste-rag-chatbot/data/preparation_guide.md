# วิธีเตรียมและจัดเก็บ: ขวดพลาสติก (PET/HDPE)
ประเภท: ขยะรีไซเคิล ทิ้งถังสีเหลือง
วิธีเตรียม: 1) เทของเหลวที่เหลือทิ้ง 2) ล้างให้สะอาด 3) แกะฉลากถ้าทำได้ 4) บีบให้แบนแล้วปิดฝา
วิธีจัดเก็บ: เก็บในที่แห้ง ใส่ถุงหรือกล่องแยกจากขยะเปียก ไม่ควรเก็บนานจนมีกลิ่นหรือแมลง

# วิธีเตรียมและจัดเก็บ: กระดาษและกล่องกระดาษ
ประเภท: ขยะรีไซเคิล ทิ้งถังสีเหลือง
วิธีเตรียม: 1) แยกส่วนที่เปื้อนอาหารหรือน้ำมันออก 2) ถอดลวดเย็บกระดาษถ้าทำได้ 3) พับกล่องลูกฟูกให้แบน 4) มัดรวมกัน
วิธีจัดเก็บ: เก็บให้แห้ง ห่างจากความชื้น เพราะกระดาษเปียกคุณภาพลดลงและรีไซเคิลยาก

# วิธีเตรียมและจัดเก็บ: ขวดแก้วและกระป๋องโลหะ
ประเภท: ขยะรีไซเคิล ทิ้งถังสีเหลือง
วิธีเตรียม: 1) ล้างให้สะอาด 2) กระป๋องบีบให้แบน 3) แก้วแตกให้ห่อกระดาษหนาและเขียนข้อความ "แก้วแตก" กำกับ
วิธีจัดเก็บ: เก็บในกล่องแข็งหรือถุงหนา แยกจากขยะอื่น ระวังขอบคมบาดมือ

# วิธีเตรียมและจัดเก็บ: กล่องเครื่องดื่ม UHT (กล่องนม น้ำผลไม้)
ประเภท: รีไซเคิลได้ผ่านจุดรับเฉพาะ
วิธีเตรียม: 1) เทของเหลวทิ้งให้หมด 2) ล้างและผึ่งให้แห้ง 3) ตัดหรือพับกล่องให้แบน
วิธีจัดเก็บ: รวบรวมไว้ในถุงแห้ง เมื่อได้ปริมาณพอสมควรนำไปส่งจุดรับกล่องเครื่องดื่มหรือธนาคารขยะ

# วิธีเตรียมและจัดเก็บ: น้ำมันพืชใช้แล้ว
ประเภท: ขยะที่ต้องจัดการเฉพาะ ห้ามเทลงท่อระบายน้ำหรือทิ้งรวมกับขยะเปียก
วิธีเตรียม: 1) รอให้น้ำมันเย็นสนิท 2) กรองเศษอาหารออก 3) เทใส่ขวดพลาสติกที่ปิดฝาแน่น
วิธีจัดเก็บ: เก็บในขวดปิดฝา ที่ร่มและห่างความร้อน แล้วนำไปจุดรับน้ำมันพืชใช้แล้วหรือโครงการของชุมชน

# วิธีเตรียมและจัดเก็บ: ถ่านไฟฉายและแบตเตอรี่
ประเภท: ขยะอันตราย ทิ้งถังสีแดงหรือจุดรับขยะอันตราย
วิธีเตรียม: 1) แยกจากขยะอื่น 2) แบตเตอรี่ลิเธียมหรือก้อนที่บวม ให้ปิดขั้วด้วยเทปกาวเพื่อป้องกันไฟลัดวงจร
วิธีจัดเก็บ: ใส่ภาชนะปิดที่ไม่ใช่โลหะ เก็บในที่แห้ง เย็น ห่างเด็กและแหล่งความร้อน ห้ามเผาหรือทุบ

# วิธีเตรียมและจัดเก็บ: หลอดไฟและขยะอิเล็กทรอนิกส์
ประเภท: ขยะอันตรายและขยะอิเล็กทรอนิกส์ ห้ามทิ้งปนขยะทั่วไป
วิธีเตรียม: 1) หลอดไฟให้ห่อกระดาษหรือใส่กล่องเดิมเพื่อกันแตก 2) อุปกรณ์ที่มีข้อมูล ให้สำรองและลบข้อมูลส่วนตัว
วิธีจัดเก็บ: เก็บรวมในกล่องแข็ง ห่างความชื้น แล้วนำไปส่งจุดรับขยะอิเล็กทรอนิกส์หรือจุดรับขยะอันตราย

# วิธีเตรียมและจัดเก็บ: หน้ากากอนามัยและขยะติดเชื้อจากบ้าน
ประเภท: ขยะติดเชื้อหรือขยะทั่วไปตามประกาศท้องถิ่น ไม่ใช่ขยะรีไซเคิล
วิธีเตรียม: 1) ตัดสายรัดหูทิ้ง 2) ใส่ถุงปิดปากให้มิดชิด 3) ล้างมือหลังจัดการ
วิธีจัดเก็บ: แยกจากขยะรีไซเคิล ทิ้งตามถังที่ท้องถิ่นกำหนด หากไม่แน่ใจให้สอบถามเทศบาลหรือสำนักงานเขต

# วิธีเตรียมและจัดเก็บ: ถุงพลาสติก ฟิล์ม และโฟม
ประเภท: ถุงพลาสติกที่สะอาดและแห้งรวบรวมไปจุดรับรีไซเคิลได้ ส่วนโฟมและถุงเปื้อนทิ้งเป็นขยะทั่วไป ถังสีน้ำเงิน
วิธีเตรียม: 1) เขย่าเศษออก 2) ปล่อยให้แห้ง 3) ซ้อนถุงรวมกันเป็นก้อน
วิธีจัดเก็บ: เก็บในถุงใหญ่ที่แห้ง รวบรวมให้ได้ปริมาณพอก่อนนำไปจุดรับ

# วิธีเตรียมและจัดเก็บ: เศษอาหารและขยะเปียก
ประเภท: ขยะอินทรีย์ ทิ้งถังสีเขียวหรือนำไปทำปุ๋ยหมัก
วิธีเตรียม: 1) สะเด็ดน้ำ 2) แยกถุงพลาสติกและกระดูกชิ้นใหญ่ออก
วิธีจัดเก็บ: ใส่ถุงหรือถังปิดฝา ทิ้งทุกวันหรือแช่เย็นเพื่อลดกลิ่นและแมลง
