# ถังขยะ 4 สี (มาตรฐานของประเทศไทย)
- ถังสีเขียว: ขยะเปียก/ขยะอินทรีย์ที่ย่อยสลายได้ เช่น เศษอาหาร เปลือกผลไม้ ใบไม้ กระดูก
- ถังสีเหลือง: ขยะรีไซเคิล เช่น ขวดพลาสติก กระดาษ แก้ว กระป๋องโลหะ
- ถังสีน้ำเงิน: ขยะทั่วไปที่ย่อยสลายยากและรีไซเคิลไม่ได้ เช่น ซองขนมเปื้อน โฟมเปื้อนอาหาร ถุงพลาสติกเปื้อน
- ถังสีแดง: ขยะอันตราย เช่น ถ่านไฟฉาย หลอดไฟ กระป๋องสเปรย์ ขวดสารเคมี ยา/ภาชนะสารเคมีหมดอายุ
ข้อควรระวัง: รูปแบบสีถังอาจต่างกันเล็กน้อยตามท้องถิ่น ควรตรวจสอบกับเทศบาลหรือสำนักงานเขต

# ขยะพลาสติกและขวดน้ำ
ขวดพลาสติกใส (PET เบอร์ 1) รีไซเคิลได้ดี ควรเทน้ำที่เหลือทิ้ง ล้างให้สะอาด บีบให้แบน แล้วปิดฝาไว้ก่อนทิ้งถังสีเหลือง
ฉลากพลาสติกหุ้มขวดควรแกะออกถ้าทำได้ เพื่อให้คัดแยกประเภทพลาสติกง่ายขึ้น
ถุงพลาสติกที่สะอาดและแห้งสามารถรวบรวมไปจุดรับรีไซเคิลได้ แต่ถุงที่เปื้อนอาหารให้ทิ้งเป็นขยะทั่วไป

# สัญลักษณ์พลาสติกรีไซเคิล (เบอร์ 1-7)
- เบอร์ 1 PET: ขวดน้ำดื่ม ขวดน้ำอัดลม รีไซเคิลง่าย
- เบอร์ 2 HDPE: ขวดนม ขวดแชมพู ถังพลาสติก รีไซเคิลได้ดี
- เบอร์ 3 PVC: ท่อน้ำ แผ่นฟิล์ม รีไซเคิลยาก
- เบอร์ 4 LDPE: ถุงพลาสติก ฟิล์มห่อ
- เบอร์ 5 PP: กล่องอาหาร ฝาขวด รีไซเคิลได้
- เบอร์ 6 PS: โฟม แก้วพลาสติกใส รีไซเคิลยาก
- เบอร์ 7 อื่น ๆ: พลาสติกผสม รีไซเคิลยาก

# กระดาษและกล่องกระดาษ
กระดาษขาว-ดำ หนังสือพิมพ์ กล่องกระดาษลูกฟูก รีไซเคิลได้ ควรเก็บให้แห้งและไม่เปื้อน
กล่องพิซซ่าที่เปื้อนน้ำมันรีไซเคิลไม่ได้ ให้ฉีกส่วนที่สะอาดไปรีไซเคิล ส่วนที่เปื้อนทิ้งเป็นขยะทั่วไป
กล่องเครื่องดื่ม UHT (กล่องนม/น้ำผลไม้) ควรล้าง พับให้แบน แล้วนำไปจุดรับรีไซเคิลกล่องเครื่องดื่ม
กระดาษทิชชูใช้แล้วและกระดาษเปียกน้ำมัน รีไซเคิลไม่ได้

# แก้วและโลหะ
ขวดแก้วล้างสะอาดแล้วทิ้งถังสีเหลือง หากแตกให้ห่อด้วยกระดาษหนาและเขียนระบุว่า "แก้วแตก" เพื่อความปลอดภัยของพนักงาน
กระป๋องอะลูมิเนียมและกระป๋องเหล็กรีไซเคิลได้ ล้างให้สะอาดและบีบให้แบน
กระเบื้อง เซรามิก และแก้วเจียระไน ไม่ควรปนกับแก้วรีไซเคิล เพราะจุดหลอมต่างกัน

# ขยะอันตรายจากครัวเรือน
ถ่านไฟฉาย ถ่านชาร์จ แบตเตอรี่ หลอดไฟ หลอดฟลูออเรสเซนต์ มีสารพิษ เช่น ปรอท ตะกั่ว ห้ามทิ้งปนขยะทั่วไป
ควรแยกใส่ภาชนะปิดแล้วนำไปทิ้งที่ถังขยะอันตรายหรือจุดรับขยะอันตรายของเทศบาล ห้างสรรพสินค้า หรือสำนักงานเขต
หลอดไฟแตกต้องระวังเศษแก้วและไอปรอท เปิดหน้าต่างระบายอากาศ ใส่ถุงมือ และห่อให้มิดชิดก่อนทิ้ง
กระป๋องสเปรย์ที่ยังมีแรงดันห้ามเจาะหรือเผา ให้ทิ้งเป็นขยะอันตราย

# ขยะอิเล็กทรอนิกส์ (E-waste)
มือถือ สายชาร์จ คอมพิวเตอร์ ทีวี เป็นขยะอิเล็กทรอนิกส์ ห้ามทิ้งปนขยะทั่วไป
ควรนำไปที่จุดรับขยะอิเล็กทรอนิกส์ ร้านจำหน่ายที่มีบริการรับคืน หรือโครงการของเทศบาล
ก่อนทิ้งอุปกรณ์ที่เก็บข้อมูล เช่น มือถือและคอมพิวเตอร์ ควรสำรองและลบข้อมูลส่วนตัวให้เรียบร้อย

# ขยะเปียกและการทำปุ๋ยหมัก
เศษอาหาร เปลือกผลไม้ ผัก เปลือกไข่ กากกาแฟ ใบไม้ นำมาทำปุ๋ยหมักได้
ขั้นตอนทำปุ๋ยหมักอย่างง่าย: 1) เตรียมถังมีรูระบายอากาศ 2) ใส่ขยะเปียก (วัสดุสีเขียว) สลับกับใบไม้แห้ง (วัสดุสีน้ำตาล) ประมาณ 1:2 3) รดน้ำให้ชื้นพอหมาด ๆ 4) กลับกองทุก 1-2 สัปดาห์ 5) ใช้เวลาราว 1-3 เดือนจนเป็นดินร่วนสีดำ
ไม่ควรใส่เนื้อสัตว์ ผลิตภัณฑ์นม หรือน้ำมันมากเกินไป เพราะส่งกลิ่นและดึงดูดแมลง
ถ้ากองส่งกลิ่นเหม็น แสดงว่าชื้นเกินไป ให้เติมใบไม้แห้งและพลิกกอง

# หลัก 3R และการลดขยะ
Reduce ลดการใช้: ปฏิเสธถุงพลาสติกและหลอดที่ไม่จำเป็น พกถุงผ้า แก้วน้ำ และปิ่นโตส่วนตัว
Reuse ใช้ซ้ำ: นำขวดแก้ว กล่อง ถุง มาใช้ซ้ำ ซ่อมแทนการทิ้ง
Recycle แปรรูปใหม่: คัดแยกขยะให้ถูกต้องตั้งแต่ต้นทาง ล้างและทำให้แห้งก่อนทิ้ง
การคัดแยกที่ต้นทางช่วยลดภาระการกำจัดขยะ ลดการฝังกลบ และเพิ่มมูลค่าวัสดุรีไซเคิล

# การขายขยะรีไซเคิลและธนาคารขยะ
ธนาคารขยะรับซื้อหรือรับฝากวัสดุรีไซเคิล เช่น ขวดพลาสติก กระดาษ แก้ว โลหะ ในชุมชนหรือโรงเรียน
ขยะที่สะอาด แห้ง และคัดแยกประเภทแล้ว จะขายได้ราคาดีกว่า
ราคารับซื้อเปลี่ยนแปลงตามตลาด ควรสอบถามร้านรับซื้อของเก่าหรือธนาคารขยะใกล้บ้านเพื่อดูราคาปัจจุบัน

# กระป๋องสเปรย์และกระป๋องแก๊สพกพา
กระป๋องสเปรย์ เช่น สเปรย์ฉีดผม สเปรย์ฆ่ายุง สีสเปรย์ สเปรย์ปรับอากาศ และกระป๋องแก๊สพกพา จัดเป็นขยะอันตราย ทิ้งถังสีแดงหรือจุดรับขยะอันตราย
ห้ามเจาะ ห้ามเผา ห้ามบีบอัด และห้ามทิ้งใกล้ความร้อนหรือแสงแดดจัด เพราะอาจระเบิดหรือติดไฟได้
ถ้าไม่แน่ใจว่าใช้หมดหรือยัง ให้ถือว่ายังมีแรงดัน ควรแยกจากขยะอื่นและเก็บในที่เย็น ห่างเด็กและแหล่งความร้อนก่อนนำไปทิ้ง
ข้อควรระวัง: บางพื้นที่รับกระป๋องที่ใช้หมดแล้วเป็นโลหะรีไซเคิล ควรสอบถามเทศบาลหรือสำนักงานเขตก่อน
