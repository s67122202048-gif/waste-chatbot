# ♻️ น้องรีไซเคิล — RAG Chatbot การจัดการขยะและรีไซเคิล

## ฟังก์ชัน
| ขอบเขต | ไฟล์ที่เกี่ยวข้อง |
|---|---|
| ถาม-ตอบสนทนา (Conversational Q&A) | `app.py`, `rag.py` (ส่งประวัติล่าสุด 6 ข้อความให้ LLM) |
| ถามด้วยภาพ (image-assisted query) | `rag.identify_image()` ระบุประเภทจากภาพ แล้วนำไปค้นคืนข้อมูล |
| แนะนำวิธีทิ้ง/จัดเก็บ/เตรียมขยะ | `SYSTEM_PROMPT` (รูปแบบคำตอบ) + `data/preparation_guide.md` |
| แสดงแหล่งอ้างอิง (citation) | คำตอบมี [1][2] และกล่อง "แหล่งอ้างอิง" แสดงไฟล์/หัวข้อ/คะแนน |
| บันทึกประวัติ + ให้คะแนน | `db.py` (SQLite: `chat_history.db`) |

## วิธีรัน
```bash
python -m venv .venv
.venv\Scripts\activate        # macOS/Linux: source .venv/bin/activate
pip install -r requirements-local.txt
copy .env.example .env        # macOS/Linux: cp .env.example .env
# แล้วตั้ง LLM_PROVIDER=openai หรือ anthropic และใส่ API key ที่ตรงกัน
streamlit run app.py
```

## เพิ่มความรู้
วางไฟล์ `.md`/`.txt` ลงใน `data/` แล้วรีสตาร์ท (ใช้หัวข้อ `#` แยกหัวเรื่องเพื่อให้ citation ชัดเจน)

## ดูคะแนนความพึงพอใจ
```bash
sqlite3 chat_history.db "SELECT rating, comment, created_at FROM feedback;"
```

## ฟีเจอร์เพิ่มเติม
- **รองรับ PDF/Word:** วาง `.pdf` / `.docx` ใน `data/` ได้ (PDF สแกนที่เป็นภาพจะอ่านไม่ได้ ต้อง OCR ก่อน)
- **ปุ่มคำถามตัวอย่าง:** แก้รายการที่ `EXAMPLES` ใน `app.py`
- **หน้า Admin** (เมนูด้านซ้าย): อัปโหลด/ลบไฟล์, เพิ่มบันทึกสั้น, ทดสอบการค้นหา, ดูผลประเมินและคำตอบที่ได้คะแนนต่ำ
  ตั้งรหัสผ่านด้วย `ADMIN_PASSWORD` ใน `.env`

## ผู้ใช้หลายคน / ความเป็นส่วนตัว / ค่าใช้จ่าย
- ประวัติแชทแยกตามรหัสสุ่มในลิงก์ (`?u=...`) ผู้ใช้บุ๊กมาร์กลิงก์เพื่อกลับมาดูประวัติ ใครมีลิงก์ก็เห็นประวัตินั้น
  (ถ้าต้องการล็อกอินจริงจัง ควรเพิ่มระบบยืนยันตัวตนภายหลัง) แชทจากเวอร์ชันเก่าจะไม่แสดงให้ผู้ใช้ทั่วไป
- ปรับโควตา/ระยะเก็บประวัติใน `.env` (ดู `.env.example`)
- ภาพที่แนบ: ย่อขนาด ลบ EXIF/ตำแหน่ง ไม่บันทึกไฟล์ แต่ถูกส่งให้ผู้ให้บริการ AI ที่คุณเลือก

## ข้อมูลของพื้นที่
คัดลอก `templates/local_info_template.md` ไปกรอกข้อมูลจริงแล้ววางใน `data/` และตั้ง `AREA_NAME` ใน `.env`

## ชุดทดสอบคุณภาพ
`python evaluate.py` (ค้นหาอย่างเดียว ฟรี) หรือ `python evaluate.py --llm` (ถามบอทจริง) หรือรันที่หน้า Admin แท็บ "ชุดทดสอบ"
เพิ่ม/แก้ข้อสอบที่ `eval/questions.json`

## ทำให้เร็วขึ้น
- คำตอบแสดงทีละส่วน (streaming) ไม่ต้องรอจนเขียนเสร็จ
- ตั้ง `EMBEDDINGS=openai` ใน `.env` เพื่อไม่ต้องโหลด torch/โมเดล 470 MB ตอนเริ่มระบบ (ใช้ `OPENAI_API_KEY` เดียวกัน)
  เมื่อสลับโหมด ระบบสร้างดัชนีค้นหาใหม่ให้เองอัตโนมัติ

## แผนที่จุดรับขยะ
- เพิ่ม/แก้จุดรับที่หน้า Admin แท็บ "จุดรับขยะ" (หรือนำเข้า CSV) ข้อมูลเก็บที่ `locations/points.csv`
- หน้า Map แสดงแผนที่และการ์ดพร้อมลิงก์ Google Maps / นำทาง (ไม่ต้องใช้ API key)
- บอทอ่านข้อมูลนี้ตอบคำถามเรื่องจุดรับได้ และใต้คำตอบเรื่องขยะอันตราย/e-waste/ธนาคารขยะ/น้ำมันพืช จะแสดงจุดรับที่เกี่ยวข้อง
- ระบบไม่มีข้อมูลจุดรับให้ตั้งแต่ต้น (ต้องกรอกเองจากแหล่งที่ตรวจสอบแล้ว)

### แผนที่แบบคลิกหมุด / จุดใกล้ฉัน
- หน้า Map: คลิกหมุดเพื่อดูรายละเอียด กดปุ่มตำแหน่งเพื่อใช้ตำแหน่งปัจจุบัน (ต้องอนุญาตในเบราว์เซอร์ และเปิดผ่าน localhost หรือ https)
  หรือเปิดสวิตช์แล้วคลิกบนแผนที่เพื่อกำหนดตำแหน่งเอง ระบบเรียงจุดจากใกล้ไปไกล ตำแหน่งเก็บแค่ในเซสชัน ไม่บันทึกลงฐานข้อมูล
- หน้า Admin แท็บ "จุดรับขยะ" มีตัวช่วยคลิกแผนที่เพื่อหาพิกัด
